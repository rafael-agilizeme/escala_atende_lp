# Escala Atende - Landing Page

Landing Page moderna, responsiva e de alta conversão para a plataforma **Escala Atende** — CRM para vendas, múltiplos atendentes e automações com inteligência artificial no WhatsApp.

## 🚀 Tecnologias Utilizadas

- **HTML5** semântico com meta tags completas de SEO e OpenGraph
- **CSS3 Moderno** (Vanilla CSS) com design tokens, tema escuro sofisticado e suporte a responsividade fluida
- **JavaScript Moderno (ES6+)** para interatividade, modais, FAQ dinâmico, menus e animações
- **Fontes**: Outfit & Plus Jakarta Sans via Google Fonts
- **Ícones**: Font Awesome 6.5.2

## 📁 Estrutura de Arquivos

```
Site Escala Atende/
├── index.html              # Estrutura principal da Landing Page
├── favicon.png             # Ícone do site
├── .gitignore              # Arquivos ignorados pelo Git
├── README.md               # Documentação do projeto
└── assets/
    ├── css/
    │   └── style.css       # Folha de estilos customizada
    ├── js/
    │   └── main.js         # Scripts de interações e utilitários
    └── img/                # Logos, screenshots, ilustrações e ícones
```

## 💻 Como Visualizar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador web ou utilizar uma extensão como o **Live Server** no VS Code:

```bash
# Ou usando npx serve
npx serve .
```
